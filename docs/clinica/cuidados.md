# Cuidados antes y después

Después de una extracción: muerde una gasa durante 30 minutos. Las primeras 24 horas no escupas, no uses pitillo y no fumes, para no soltar el coágulo. Come blando y frío ese día. Si el sangrado no para después de una hora, llámanos.

Después de una endodoncia es normal sentir molestia al morder por 2 o 3 días. No mastiques duro con ese diente hasta que tenga su restauración final.

Después de un blanqueamiento: durante 48 horas evita café, té, vino tinto, gaseosas oscuras y cigarrillo. Es normal algo de sensibilidad al frío los primeros días.

Con brackets: cepíllate después de cada comida y usa cepillo interdental. Evita comidas duras o pegajosas como caramelos, chicle y maíz pira. Si un bracket se suelta, no es urgencia: avísanos y lo pegamos en el siguiente control.

Si tienes dolor de muela mientras llega tu cita: puedes tomar un analgésico de venta libre según el empaque, y evita lo muy frío o muy caliente. Si hay inflamación en la cara, fiebre o el dolor no te deja dormir, es una urgencia: llámanos para atenderte el mismo día. Este chat no reemplaza una valoración.
